Owner decisions and open defaults

The mockup shows the recommended option for each. Details are in docs/ux/m6-design.md §1 and ADR 0019.

  1. Spec §1: decided (owner, 2026-11-24). §1 is reworded: gradients are visual region fills with a machine result, and the timeline is undo history plus recipes, not a feature tree.
  2. Machine layers and styled strokes. Recommended: Stroke styles: Centreline by default, so cuts never change by surprise, with Styled as a per-layer option (dashes become perforations).
  3. Gradients on regions only, following #451. Decided (owner, 2026-11-24): each gradient fill has a Rotate with shape option, on by default as in Illustrator and Affinity.
  4. History is linear. Jumping back and then editing drops the later steps, as Photoshop does by default. Branching would come later.
  5. Default cap and join: Round, matching today's canvas. The alternative is Illustrator's butt and miter.
  6. Wide strokes on a plotter plot as outline + hatch at the pen width, so they look solid.

Needs measuring first

Spikes S1–S5 (ADR 0019): the variable-width outline engine, including the owner's question of biarcs only vs kept cubic Béziers (pending S1), calligraphic accuracy, canvas draw cost, OS font enumeration, and an auto-trace benchmark. Auto trace is Locus's own implementation of the published Potrace algorithm (owner decision).
